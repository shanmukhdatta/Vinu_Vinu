# Community code of conduct

We welcome contributors of different levels of experience, backgrounds and communication styles. Treat other contributors respectfully. Critique code and evidence, not individuals.

**Expected:** helpful and specific feedback, patience with newcomers, accurate claims about test evidence, respect for maintainers' time, honest attribution and responsible handling of reports.

**Not acceptable:** harassment, discriminatory insults, threats, doxxing, sharing people's credentials, repeated off-topic disruption or deliberate misrepresentation of another contributor's work.

Maintainers may ask someone to revise a comment, lock a thread, reject a contribution or limit participation to protect the community. When reporting community misconduct, contact the repository maintainer via an appropriate private GitHub channel where available. Do not publish identifying/sensitive details in a public issue.

The aim is a friendly, technically grounded community in which disagreement about implementation details stays constructive.
