# Vinu Vinu v0.2.0 — Windows community preview

Source: https://github.com/shanmukhdatta/Vinu_Vinu

The release includes the sky-blue Windows app for audio mirroring to already-connected playback endpoints, per-output volume, EQ, manual delay, Voice Clarity, an Audio Hub and bounded queue recovery diagnostics.

Download VinuVinu-win-x64.zip, unzip it and run VinuVinu.exe. The binary is unsigned. The ZIP includes both MIT license notices and a quick-start guide.

The GitHub Windows build does not verify simultaneous playback through physical Bluetooth headphones. The number of usable devices depends on Windows drivers and adapter hardware. Manual delays cannot guarantee acoustic synchronization. DRM-protected media may not be capturable.
