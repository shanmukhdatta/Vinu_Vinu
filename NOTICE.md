### SoundSync original author

The primary WPF source is a derivative of [SoundSync by Sugumar S](https://github.com/sugumar247/SoundSync), pinned source commit \`858f54a5b91051a547b226701225fb7e9c87069b\`. The original MIT notice is retained without changes at [src/VinuVinu/UPSTREAM_LICENSE](src/VinuVinu/UPSTREAM_LICENSE). The source was imported as files rather than preserving its original commit history.

### Independent prototype and current work

The old WinForms prototype appears at \`legacy/SyncCast/\`. Its root MIT notice credits SyncCast contributors. Later Vinu Vinu improvements are retained in the project's Git history.

### Package dependencies

NAudio, Hardcodet.NotifyIcon.Wpf, xUnit, Moq and other build dependencies are used under their respective licenses. Check NuGet package metadata when redistributing or introducing dependencies.

### Design and outside reference projects

The application's friendly blue styling uses original WPF shapes, not licensed Doraemon character illustrations. Snapcast was referenced for general networking architecture, not copied or linked into the MIT source tree. Contributor PRs must declare code copied from any other repository and retain its notices.
