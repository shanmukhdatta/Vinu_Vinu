THE IDEA

Good audio is better shared.

Watching a movie together? Sharing music in a room? Need sound from more than one Windows output? Here's the problem we're trying to solve.

THE PROBLEM
✕

One PC, one default output

Windows typically sends an app's sound to its selected default speaker. Sharing the same sound across different devices can be awkward, especially with Bluetooth.

THE VINU VINU APPROACH
✓

One source, several outputs

Vinu Vinu captures the default Windows playback mix and sends copies to other outputs that Windows already exposes, each with individual settings.

WHAT YOU CAN DO

A little app. A lot of control.

A cheerful interface built around the useful details of Windows audio sharing.

♫

Multi-output sharing

Mirror one Windows playback mix to the additional audio endpoints you've selected.

◉

Your volume, your way

Adjust volume for each mirrored output and use the equalizer to customize the sound.

◷

Manual delay controls

Fine-tune each output's delay when different speakers sound out of step. Exact acoustic sync is not guaranteed.

▦

Saved speaker groups

Save favorite combinations and apply them again after stopping a sharing session.

◌

Voice Clarity preset

A gentle playback EQ to bring dialogue forward. Not microphone noise cancellation.

⌁

Diagnostics and verifier

See queue recovery counts and use a test-tone verifier to inspect digital audio delivery.

HOW IT WORKS

Three steps to sound together.

Set up the devices in Windows before opening Vinu Vinu. No special driver or pairing magic is built into the app.

Read detailed Windows setup instructions ↗
01

Connect your devices

Pair Bluetooth headphones or attach USB and wired speakers through Windows. Confirm each shows as an active playback device.

02

Choose your outputs

Launch Vinu Vinu, leave the Windows default speaker as the source, and select the additional outputs you'd like to mirror.

03

Start audio sharing

Press Start Audio Sharing, play audio on the PC, and adjust volume, delay and EQ for the connected endpoints.

QUICK QUESTIONS

Things worth knowing.

Does it connect an unlimited number of Bluetooth headphones?

No. It mirrors audio to the active playback endpoints that Windows and your adapter expose. The number that can actually run depends on hardware, drivers, codec profiles and system load.

Does the website play or stream my Windows audio?

No. This is a project information website. Vinu Vinu is a native Windows desktop application; audio sharing happens through that installed application, not in this web page.

Is the desktop app free and open source?

Yes. The source is publicly available under MIT terms with the original SoundSync author's attribution preserved. Release downloads, when published, are attached to GitHub Releases.

Are all speakers perfectly synchronized?

Not guaranteed. Different devices have independent audio buffering and clock behavior, especially over Bluetooth. The delay controls are manual and hardware-level acoustic synchronization requires separate measurement.
