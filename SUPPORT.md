# Getting help

For user-facing setup, begin with [README.md](README.md) and [docs/TESTING.md](docs/TESTING.md). Windows must expose headphones and speakers as active audio endpoints before Vinu Vinu can use them. The app cannot increase a Bluetooth adapter's physical capabilities or guarantee timing alignment.

If your issue is reproducible, open a [GitHub bug report](https://github.com/shanmukhdatta/Vinu_Vinu/issues/new/choose). Include Windows version, relevant audio devices without stable IDs, app version or commit SHA, steps and the error message. Do not share security credentials, raw audio, private identifiable device information or unreviewed JSON diagnostics.

For ideas and feature requests use the issue template. For a security problem, follow [SECURITY.md](SECURITY.md) instead of posting the details publicly.

Community support is best effort; this project does not offer a guaranteed response time.
